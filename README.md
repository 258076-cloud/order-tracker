# 📦 برنامج متابعة الطلبيات بين المحاسبة والمخزن

برنامج بسيط بلغة Python باستخدام Streamlit وSQLite، يوثّق كل مرحلة من مراحل الطلبية
(الإنشاء - الإرسال - الاستلام - التجهيز - التسليم) بالتاريخ والوقت، لحل مشكلة
"الطلبية لم تصل" بين المحاسبة والمخزن.

## 📁 محتويات المشروع
- `app.py` — البرنامج بالكامل (واجهة + قاعدة بيانات + منطق العمل).
- `requirements.txt` — المكتبات المطلوبة.
- `orders.db` — سيتم إنشاؤها تلقائياً عند أول تشغيل (لا حاجة لإنشائها يدوياً).
- `uploads/` — مجلد يُنشأ تلقائياً لحفظ ملفات PDF وصور الطلبيات.

## ⚙️ خطوات التشغيل

### 1) تثبيت المتطلبات
افتح الطرفية (Terminal) داخل مجلد المشروع ثم نفّذ:

```bash
pip install -r requirements.txt
```

> ملاحظة: مكتبة `pytesseract` تحتاج أيضاً إلى برنامج **Tesseract OCR** مثبتاً
> على جهازك حتى تعمل ميزة استخراج النص من الصور تلقائياً.
> إذا لم يكن مثبتاً، سيعمل البرنامج بشكل طبيعي، لكن بدون هذه الميزة فقط،
> وسيطلب من المحاسبة إدخال عدد الأصناف يدوياً.
>
> - ويندوز: حمّل المثبت من الموقع الرسمي لمشروع Tesseract وثبّته.
> - ماك: `brew install tesseract`
> - لينكس (Ubuntu): `sudo apt install tesseract-ocr`

### 2) تشغيل البرنامج

```bash
streamlit run app.py
```

سيفتح البرنامج تلقائياً في المتصفح على الرابط:
`http://localhost:8501`

### 3) الوصول من الهاتف
بما أن الواجهة مبنية بالكامل بـ Streamlit فهي تعمل مباشرة من متصفح الهاتف،
بشرط أن يكون الهاتف على نفس شبكة الواي فاي الخاصة بالكمبيوتر الذي يشغّل البرنامج.
افتح الرابط الذي يظهر في الطرفية باسم **Network URL** (مثل: `http://192.168.x.x:8501`)
من متصفح الهاتف.

## 👤 إنشاء حسابات جديدة
بعد تسجيل الدخول بأي حساب، افتح قسم **⚙️ الإعدادات** من الشريط الجانبي (يسار/أعلى الشاشة).
من هناك تقدر تنشئ حساب جديد (محاسبة أو مخزن) باسم مستخدم وكلمة مرور من اختيارك،
وتشوف قائمة كل الحسابات الموجودة حالياً.

## 🗑️ الحذف التلقائي للطلبيات القديمة
من نفس قسم **⚙️ الإعدادات**، فيه خيار لتحديد عدد الأيام (افتراضياً 30 يوم = شهر تقريباً).
بعد مرور هذه المدة على **تسليم الطلبية للمحاسبة فعلياً**، يتم حذفها تلقائياً مع ملفها المرفق
عند أول فتح للبرنامج. **يهم التنويه أن الطلبيات التي ما زالت قيد التنفيذ (لم تُسلَّم بعد) لا تُحذف أبداً**،
حفاظاً على سلامة المتابعة وحل مشكلة "الطلبية لم تصل". فيه أيضاً زر لتشغيل الحذف يدوياً في أي وقت.

## 🧩 كيف يحل البرنامج مشكلة "الطلبية لم تصل"؟
كل طلبية تمر بخمس مراحل، وكل مرحلة تُسجَّل تلقائياً بالتاريخ والوقت في قاعدة البيانات:
1. **إنشاء الطلبية** (من طرف المحاسبة).
2. **الإرسال إلى المخزن** (زر خاص بالمحاسبة).
3. **استلام المخزن** (زر خاص بالمخزن — دليل صريح أن الطلبية وصلت فعلاً).
4. **تجهيز الطلبية** (من طرف المخزن).
5. **تسليم الطلبية للمحاسبة** (من طرف المخزن).

بهذا الشكل، لا يمكن لأي طرف أن يدّعي عدم وصول الطلبية، لأن كل خطوة موثّقة
بوقت وتاريخ دقيقين، وتظهر في "الخط الزمني" (Timeline) الخاص بكل طلبية.

## 🛠️ إمكانية التطوير مستقبلاً
البرنامج مكتوب بأسلوب بسيط ومباشر (دوال منفصلة لكل عملية) حتى يسهل توسيعه لاحقاً،
مثل: إضافة صلاحيات مستخدمين متعددين لكل قسم، إشعارات، تقارير PDF جاهزة، أو ربطه
بقاعدة بيانات أكبر مثل PostgreSQL دون تغيير جوهري في منطق البرنامج.

## 🌐 نشر البرنامج كموقع ويب (Streamlit Community Cloud) — مجاني

### الخطوات:
1. أنشئ حساباً مجانياً على GitHub (إذا ما عندك): https://github.com
2. أنشئ مستودع (Repository) جديد وارفع له ملفات المشروع:
   `app.py`, `requirements.txt`, `packages.txt`
   (لا ترفع `orders.db` ولا مجلد `uploads` — ملف `.gitignore` المرفق يتجاهلهما تلقائياً)
3. اذهب إلى: https://share.streamlit.io وسجّل دخول بحساب GitHub نفسه.
4. اضغط "New app"، اختر المستودع الذي رفعته، وحدد أن الملف الرئيسي هو `app.py`.
5. اضغط "Deploy". بعد دقيقة أو دقيقتين، رح يعطيك رابط ويب مباشر مثل:
   `https://your-app-name.streamlit.app`
   هذا الرابط يفتح من أي جهاز (كمبيوتر أو هاتف) بدون تثبيت أي شيء.

### ملف packages.txt
هذا الملف موجود بالمشروع ويحتوي على `tesseract-ocr` — وهو مطلوب حتى تعمل ميزة
استخراج النص من الصور (OCR) على الاستضافة السحابية، لأن هذه المكتبة نظامية
وليست مجرد مكتبة بايثون عادية.

### ⚠️ تنويه مهم
الاستضافة المجانية تستخدم تخزيناً مؤقتاً: كل مرة يُعاد فيها تشغيل التطبيق أو تحديث الكود،
قد يُفقد ملف `orders.db` وكل الملفات المرفوعة في `uploads`. هذا ممتاز للتجربة والعرض،
لكن للاستخدام الفعلي طويل الأمد بالمخزن، يُفضّل لاحقاً ربط البرنامج بقاعدة بيانات
سحابية دائمة، دون تغيير جوهري في منطق البرنامج.
